Daily Expense Tracker

Daily Expense Tracker is a simple application designed to help users manage their daily expenses.

Features

- Add daily expenses
- Enter amount, date, category, and description
- Calculate total expenses
- Track spending
- Manage your budget effectively

Purpose

The main purpose of this project is to help users keep track of their daily spending and manage their money in an organized way.

Technologies Used

- C Programming

How It Works

Users enter their expense details, and the application stores and calculates the expenses to help them understand their daily spending.
